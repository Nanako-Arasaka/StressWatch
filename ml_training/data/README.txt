# StressWatch ML Dataset Export

This folder contains CSV files converted from the uploaded Apple Health export.

## Files

- `stresswatch_ml_daily_features_full_hrv_period.csv`
  - Date range: 2026-02-05 to 2026-05-30
  - Rows: 115
  - Starts from the first available Apple Watch HRV SDNN record.

- `stresswatch_ml_daily_features_recent_90d.csv`
  - Date range: 2026-03-02 to 2026-05-30
  - Rows: 90
  - Recommended first dataset for Python / scikit-learn experiments.

- `dataset_summary.json`
  - Parse summary and weak label counts.

- `parse_apple_health_to_stresswatch_ml_csv.py`
  - Local script template you can run on future Apple Health exports.

## Main fields

- `avg_hrv_sdnn`, `min_hrv_sdnn`, `max_hrv_sdnn`, `hrv_count`
- `avg_heart_rate`, `min_heart_rate`, `max_heart_rate`
- `resting_heart_rate`
- `sleep_hours`, `rem_sleep_hours`, `core_sleep_hours`, `deep_sleep_hours`, `awake_hours`
- `steps`, `active_energy_kcal`, `exercise_minutes`, `stand_hours`
- `hrv_7d_baseline`, `hrv_deviation_percent`
- `resting_hr_7d_baseline`, `resting_hr_deviation`
- `sleep_7d_baseline`, `sleep_ratio`
- `rule_stress_score`, `rule_recovery_score`, `live_stress_estimate`
- `weak_label`, `data_confidence`
- `user_label` (optional; joined from local Daily Check-in records when `--user-labels` is provided)

## Important notes

- This dataset is for personal wellness trend analysis and machine-learning experiments only.
- It is not a medical dataset and should not be used for diagnosis, treatment, or emergency decisions.
- `weak_label` is generated by a rule-based heuristic from HRV deviation, resting heart rate deviation, sleep ratio, and activity level.
- `user_label` stores the user's local subjective Daily Check-in label for that date and does not replace `weak_label`.
- Apple Health HRV from Apple Watch is `heartRateVariabilitySDNN`.
